# OneSmarter Website

Public website for OneSmarter, built with React and Vite.

## Framework

- React
- Vite
- React Router
- Tailwind utility classes

## Main Scripts

```bash
npm install
npm run dev
npm run build
npm start
npm run preview
node scripts/generate-ai-search-files.js
node generate-sitemap.js
```

## Docker

Build and run in production:
```bash
docker compose up --build -d
```
See [DOCKER.md](file:///c:/Onesmarter/Maintance/Onesmarter%20Website/New_OneSmarter_Website/DOCKER.md) for full instructions and options.

## Important Directories

- `src/components` - React page, layout, navigation, footer, and content components.
- `src/data/siteDirectory.js` - public route directory, SEO metadata, AI summaries, and trust wording source.
- `public` - static assets, generated markdown mirrors, `llms.txt`, `llms-full.txt`, `robots.txt`, and `sitemap.xml`.
- `scripts` - generation utilities for AI/search files.
- `dist` - production build output generated by Vite.

## AI And Search Generation

Run this after route, metadata, service description, or public positioning changes:

```bash
node scripts/generate-ai-search-files.js
node generate-sitemap.js
```

The AI/search generator creates public LLM files, markdown mirrors for active routes, `robots.txt`, and a sitemap using the shared site directory. `llms-internal.txt` should not be present in `public` or `dist`.

## Build And Deployment Notes

Run a production build before deployment:

```bash
npm run build
```

The app is a React single-page application. Unknown routes currently redirect to the homepage. A dedicated Not Found page is recommended before production launch.
